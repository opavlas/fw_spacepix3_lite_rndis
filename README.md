# fw_spacepix3_lite_rndis

Firmware for SpacePix3 Lite with RNDIS support.

## Sharing and Collaboration

### How to Share an Invite Link to This Project

There are several ways to share access to this GitHub repository:

#### 1. For Repository Owners/Admins: Inviting Collaborators

If you have admin access to this repository, you can invite collaborators directly:

1. Navigate to the repository on GitHub: `https://github.com/opavlas/fw_spacepix3_lite_rndis`
2. Click on **Settings** (gear icon)
3. In the left sidebar, click **Collaborators and teams**
4. Click **Add people** button
5. Enter the GitHub username or email address of the person you want to invite
6. Select their permission level (Read, Triage, Write, Maintain, or Admin)
7. Click **Add [username] to this repository**
8. The person will receive an email invitation with a link to accept

#### 2. Sharing the Repository URL

For public repositories, you can simply share the repository URL:
```
https://github.com/opavlas/fw_spacepix3_lite_rndis
```

Anyone with this link can:
- View the code
- Clone the repository
- Fork the repository
- Submit issues (if enabled)
- Submit pull requests (if enabled)

#### 3. For Private Repositories: Organization Invites

If this is a private repository within an organization:

1. The organization admin can invite members to the organization
2. Once they're organization members, they can be added to specific repositories
3. Navigate to: `https://github.com/orgs/[org-name]/people` to manage organization members

#### 4. Using GitHub Repository Invitation Links

For private repositories, GitHub generates invitation links when you invite collaborators. These links are sent via email automatically and look like:
```
https://github.com/opavlas/fw_spacepix3_lite_rndis/invitations
```

### Contributing

If you've been invited to collaborate on this project:

1. Accept the invitation email from GitHub
2. Clone the repository:
   ```bash
   git clone https://github.com/opavlas/fw_spacepix3_lite_rndis.git
   cd fw_spacepix3_lite_rndis
   ```
3. Create a new branch for your changes:
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. Make your changes and commit them
5. Push to your branch and create a Pull Request

### Permission Levels

- **Read**: Can view and clone the repository
- **Triage**: Can manage issues and pull requests
- **Write**: Can push to the repository
- **Maintain**: Can manage the repository without access to sensitive actions
- **Admin**: Full access to the repository
